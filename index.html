What is vibe coding?

Vibe coding means telling an AI what you want in plain language and letting it write the code. You act like a director: you describe, look at the result, and ask for changes until it feels right.

This workshop is part of Vibes by Hack Club. By the end, every person in the room will have shipped a project of their own.

Who it's for

Students with zero coding experience. Curious beginners are the point.

How long

About 90 minutes, from blank page to live link.

What you need

A laptop, an internet connection, and a free AI chat tool.

Build your project in 7 steps

Follow these in order. Each one takes about ten minutes.

  1. Pick a small idea

    Choose something you'd enjoy making: a fan page, a quiz, a countdown to summer break, a tiny game. Small ideas finish. Big ideas stall.

  2. Open an AI tool

    Use any AI chat tool that can write code, such as Claude. Start a new chat so it has a clean slate.

  3. Write your first prompt

    Say what it is, who it's for, and how it should look. Ask for a single index.html file with the CSS inside it.

    Make a one-page website for a countdown to summer
break. Bright yellow and blue, big numbers, and a
button that changes the background color.

  4. Save and open the result

    Copy the code into a file called index.html, then double-click it. It opens in your browser.

  5. Iterate

    Ask for one change at a time: "make the title bigger", "add a confetti animation", "the button is hard to read". Be specific about what's wrong.

  6. Fix what breaks

    If something doesn't work, tell the AI exactly what you see, or paste in the error message. Test on your phone too.

  7. Put it online

    Upload your files to a free host like GitHub Pages or Netlify. You'll get a link anyone can open.

How to send your project

Before you submit, check that:

  • Your project has a live link that opens without logging in.
  • It works on a phone and a laptop.
  • You can explain, in a sentence, what you asked the AI to do.
  • Your code is in a public GitHub repository.

When your link works, send it here.
