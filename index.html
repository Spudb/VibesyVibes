What is vibe coding?

Vibe coding means telling an AI what you want in plain language and letting it write the code. You act like a director: you describe, look at the result, and edit it the way you want.

This workshop is part of Vibes by Hack Club. By the end, every person in the room will have shipped a project of their own.

Who it's for

Students with zero coding experience. Curious beginners are the point.

How long

About 60 minutes, from blank page to live link.

What you need

A laptop, an internet connection, a free AI chat tool, and your ideas!

Build your project in 8 steps

Follow these in order. Each one takes about ten minutes.

  1. Pick a small idea

    Choose something you'd enjoy making: a fan page, a quiz, a countdown to summer break, a tiny game. Small ideas finish. Big ideas stall.

  2. Open an AI tool

    Use any AI chat tool that can write code. Start a new chat so it has a clean slate.

  3. Write your first prompt

    Say what it is, who it's for, and how it should look. Ask for two files, the index.html file, and the style.css file.

  4. Save and open the result

    Copy the code into a file called index.html and style.css, then double-click the index.html file. It opens in your browser.

  5. Commit Number 1!

    upload the files to a new github repo, and commit to save them.

  6. Edit

    Make 5 edits on your project's code. It could be changing the text style, color, change anything that you want to.

  7. Commit number 2!!

    Make a commit and write what you edited in your project.

  8. Add Features

    Add 3 features to your website. Make new things in your website.

  9. Commit Number 3!!!

    After finishing the edits in your website, commit one more time to save your edits.
